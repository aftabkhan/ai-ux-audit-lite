# AI UX Audit — Portfolio Showcase Release

## Release objective
Ship the current public AI-assisted UX Audit experience as a credible portfolio showcase.

## In scope
- Define an audit with product/user/task context.
- Upload one or more ordered screenshots.
- Run evidence-grounded AI analysis.
- Review findings across the professional audit dimensions.
- Human-in-the-loop accept/dismiss/severity override/reviewer notes.
- Evidence provenance in findings and exports.
- Markdown, JSON and print/PDF export.
- Existing public provider flow, validation, timeout handling and safe errors.

## Deferred from showcase release
- Product Lab invitation/session integration.
- Reviewer-owned persistent history exposed through authenticated UI.
- Cross-subdomain SSO and Product Lab ACL wiring.

These deferred capabilities remain implemented only behind the server-side persistence boundary where applicable and are not represented as available in the public showcase.
